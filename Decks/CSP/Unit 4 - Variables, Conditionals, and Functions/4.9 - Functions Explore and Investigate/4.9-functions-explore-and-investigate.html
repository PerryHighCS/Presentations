The updateScreen() Pattern

The updateScreen() Pattern

In this pattern, variables hold the information, and one function puts it on the screen.

updateScreen is declared once. It sets every output from the variables.

It is called when the app starts and after every change to a variable.

updateScreen Pattern
1var count = 0;
2updateScreen();
3
4onEvent("upButton", "click", function() {
5  count = count + 1;
6  updateScreen();
7});
8
9onEvent("downButton", "click", function() {
10  count = count - 1;
11  updateScreen();
12});
13
14function updateScreen() {
15  setText("countLabel", count);
16  if (count > 20) {
17    setProperty("countLabel", "text-color", "green");
18  }
19}
The first fragment highlights the declaration (lines 14 to 19); the second highlights the three calls (lines 2, 6, and 11). Point out that the event handlers never call setText themselves: they only change count, and updateScreen does the rest.
Check In

How many times is updateScreen called in the updateScreen pattern code?

Answer: 3 (once at the top, and once in each event handler). Students who answer 4 are counting the declaration line, which defines the function but does not call it.
Vocabulary

Functions and Function Calls

Function

A named group of programming instructions. A function is also called a procedure.

function updateButton() {
  setProperty("bigButton", "width", 100);
  setProperty("bigButton", "height", 200);
  setProperty("bigButton", "text", "Click me!");
}

Function Call

A command that runs the code inside a function.

updateButton();
These are the AP CSP terms. The College Board uses "procedure" on the exam, so students should recognize both words.
Exit Ticket

What is the difference between declaring a function and calling a function? Why is it useful to declare it once and call it many times?

Strong answers say that declaring gives a group of instructions a name without running them, and calling runs them. Writing the code once means less repetition and only one place to fix or change, just like the chorus in Style 2.
