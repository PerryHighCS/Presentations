Conditionals Explore

Today you will learn how a program uses a true or false value to make a decision. You will work through every example on paper with a partner.

Unit 4 Lesson 5. This is the Explore lesson for conditionals, run unplugged. Students work on paper handouts instead of the Digital Manipulatives slides, so they only need a pencil. Hand out each page as the deck reaches it. Full JavaScript if/else syntax comes in the next lesson; today is about the idea of selection.
Warm Up

Imagine you need to decide what to wear to an event. What are two pieces of information you would want to know?

With a partner, describe how you would use that information to make your decision.

Give partners about two minutes. Collect a few answers on the board, such as the temperature, whether it is raining, whether the event is formal, or whether it is indoors or outdoors. Push for a rule: "If it is below 50 degrees, I wear a jacket." Each piece of information is something a program would store in a variable, and each rule is a decision. Save the board notes: students return to this idea on the last handout to build their own flowchart. Handout: no space needed here; this is spoken.

Programs store information as different types of values. So far you have used numbers and strings. Today you will add a third type.

Numbers

Numbers are made of the digits 0 through 9 and have no quotes.

Strings can hold any characters, and they always go inside double quotes.

Boolean Expressions

Comparison Operators

A Boolean expression is an expression that evaluates to true or false. A comparison operator is your clue to stop and evaluate for a Boolean value.

3 < 8 evaluates to true
<less than<=less than or equal to
>greater than>=greater than or equal to
==equal to!=not equal to
Read 3 < 8 aloud as a question: "Is 3 less than 8?" The answer is yes, so the expression evaluates to true. Stress that == is two equal signs: it asks whether two values are equal. It does not assign a value the way = does with a variable. Handout 1 lists all six operators at the top of part 2.
Boolean Expressions

Reduce, Then Compare

Before you can compare, each side of the comparison operator must be reduced to one value. Then the comparison turns those two values into one Boolean.

start3 + 6<8
reduce each side9<8
comparefalse

The right side is already a single value, so only the left side needed work. Since 9 is not less than 8, the expression evaluates to false.

Model this one slowly. Students should write each reduction on its own line, the same way the slide does. Support move: have students underline the comparison operator first and write each reduced side underneath it.

Making a Decision

Can I go to the movies? I’m allowed to go if it is before 8 o’clock.

What information do I need to know to answer this question?

I need to know the time. That is a number, so I will store it in a variable named time.

For these examples, time is the hour in the evening: 7 means 7 p.m., 8 means 8 p.m., and 9 means 9 p.m.

Making Decisions

Testing the Boundary

The boundary value 8 is the only test that tells time < 8 apart from time <= 8. At 7 and at 9, both conditions give the same answer.

time < 8

substitute8<8
comparefalse

You stay home. This matches the rule, because 8 o’clock is not before 8.

time <= 8

substitute8<=8
comparetrue

You go to the movies. This breaks the rule, because <= includes 8.

When you test a condition, always include a value right on the boundary. That is where a wrong operator shows up.

This is the answer to the handout question "Why does time = 8 matter?" Listen for "before 8 excludes 8." Testing at the boundary is a habit students will use every time they test code.

Combining Conditions

Logical Operators

To check the money AND the age in one diamond, we need a way to combine two Boolean values into one.

Boolean values are a type of information, so they can be used in a Boolean expression too. Logical operators combine or change Boolean values.

&&AND

True only when both sides are true.

||OR

True when at least one side is true.

!NOT

Flips a Boolean to its opposite.

true && false evaluates to false
Read && as "and", || as "or", and ! as "not." On most keyboards the | key is above Enter. For true && false: the expression claims that both values are true, and one of them is not, so the result is false. This answers the question that closed the two-decision slide. Combining Conditions

Using NOT With a Comparison

What if we want to flip the result of a whole comparison, like 3 > 5? The comparison has to be evaluated before ! can flip it.

Parentheses work in a Boolean expression the same way they do in math: they group part of the expression, and you evaluate inside them first.

start!(3 > 5)
compare inside!false
fliptrue
Students know parentheses from arithmetic order of operations (the (7 - 3) * 3 drill on Handout 1), so connect to that: the group inside the parentheses is evaluated first, then the ! flips that single Boolean result. Without the parentheses, ! would try to apply to just the 3. The next slide uses parentheses again to group each side of && and ||.

Combining Conditions

What Happens With $50?

The condition money == 40 is only true when money is exactly 40. With $50, 50 == 40 is false, so the rule turns me away.

Is that what we meant? No. Having 40 dollars means having enough money, so $50 should be fine. We meant at least $40.

Which comparison operator means “at least”? On your handout, revise the condition.

(money >= 40) && (age > 14)

The “over 14” part was already right: age > 14 excludes 14, just as the rule does.

Give partners a moment to answer "Is that what we meant?" before revealing. Then have them write the revised condition before you show it. Listen for the difference between "exactly 40" and "at least 40," and between "over 14" and "14 or older." The handout has lines for the explanation and for the revised condition.

Wrap Up

Key Takeaways: Comparisons

A Boolean value is a data type that is either true or false.

The comparison operators <, >, <=, >=, ==, and != signal a Boolean expression.

Each side of the comparison is reduced to a single value, and then the two values are compared to produce true or false.

Always test the boundary, where the two sides are equal.

10 < 2evaluates tofalse
4 == 4evaluates totrue
Ask students to restate each takeaway in their own words before moving on.
Wrap Up

Key Takeaways: Decisions

The logical operators &&, ||, and ! (AND, OR, NOT) combine or change Boolean values. Each side is reduced to a single Boolean first.

A truth table shows how the reduced values combine into one Boolean result.

A conditional uses that single Boolean value to choose which action runs, and a flowchart shows the steps of that decision.

true && falseevaluates tofalse
true || falseevaluates totrue
Listen for students to name comparing and deciding as two related but separate steps: a comparison produces a Boolean value, and a conditional uses that value to choose an action. Handout (end of lesson, if time allows): a reflection question, "Can a computer evaluate an expression to something between true and false? How could you write an expression to deal with a maybe answer?" and a vocabulary matching set: Boolean expression, logical operator, &&, ||, !, And, Or, Not.
