Two Ways for Programs to Run

Sequential vs. Event-Driven

Sequential Programming

  • Program statements run in order, from top to bottom.
  • No user interaction.
  • Code runs the same way every time.

Event-Driven Programming

  • Some statements run only when triggered by an event, like a mouse click or a key press.
  • Programs run differently each time, depending on user interactions.
