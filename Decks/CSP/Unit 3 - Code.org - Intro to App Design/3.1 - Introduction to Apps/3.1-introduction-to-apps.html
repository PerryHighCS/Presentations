Concept

Purpose and Function

In developing apps, it’s important to understand both their purpose and function. The purpose helps the developer focus on creating an app with specific goals in mind.

The function of an app is how it meets its purpose. To explore the function of an app, we need a little more background information…

Concept · Continued

Purpose and Function

The video explained input, storage, processing, and output. Today we are going to focus on input and output.

An app on a phone gets input from a user or from another program in many different ways, and displays, or in the case of sound plays, output. The output of a program is usually based on its inputs.

Let’s think about how the sample apps we looked at handle inputs to create outputs.
