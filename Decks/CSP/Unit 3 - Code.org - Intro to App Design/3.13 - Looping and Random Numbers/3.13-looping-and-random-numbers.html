Looping and Random Numbers

The Problem

Repeating with Functions?

As we have grown as programmers, we have focused on breaking a large task into smaller pieces and giving each piece a function.

Often some portion of the task needs to be repeated many times. We could just call the same function over and over. That works for calling a function five times, but if it needs to run 1,000,000 times we need a better solution.

Today

Repeating with Loops

Today we explore a programming construct called a loop, which lets us repeat a set of commands many times. We will also loop through commands with random input, giving us many instances of random output.

Just like last class, this is useful both for testing our code and for adding more variety to our drawings. Let’s see how loops work.
