FRQ

Do Programmers Memorize Every Command?

So far we have drawn turtle art with only a few commands. Most languages, including the JavaScript in App Lab, have hundreds or thousands of commands.

Do you think programmers memorize all of the commands in a programming language? If not, how is anyone ever able to use an entire programming language?

Why This Matters

Memorization Is Out

There is no way to memorize it all, especially if you use more than one language. Programmers were not born knowing how a language works, and they do not have perfect memories either. Instead they rely on written documentation to learn new features and recall how they work.

  • Programmers ask each other for help.
  • They use reference guides, online or in print, to learn how to use a language.
  • They read old code in the language to learn how to write new code.
Today’s Skill

Reading the Documentation

By the end of the day we hope to be better turtle artists, but we are also building another important skill: reading the documentation of a programming language.

Before you ask me or a classmate for help today, read through the documentation, try the examples, and talk with friends. Then talk to me. It may be slower going today, but over the long term it will make you a much more confident programmer.
