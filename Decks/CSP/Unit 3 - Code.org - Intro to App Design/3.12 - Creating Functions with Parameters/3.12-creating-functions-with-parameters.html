How do parameters make commands more useful?

Recap

Commands with Parameters

In the previous lesson we used a lot of new turtle commands. Some of them accept a parameter, or even several parameters, which let us pass values to the function.

That let us make far more interesting images by specifying precisely how far the turtle should move or turn, and it introduced the ability to choose specific pen sizes and colors.

Why This Matters

Parameters Are Very Useful

Think about turning the turtle some amount. Without a parameter we would need 360 different functions, one for each number of degrees we might want to turn.

A parameter lets a single function be a general solution to a whole group of problems. Today we will learn how to create functions with parameters for ourselves.

Wrap-Up

Why Parameters Matter

  • A parameter lets you build one generalized solution to a whole class of problems instead of solving many specific problems one at a time.
  • Parameters remove repetitive functions, which makes code easier to write, read, and change.
  • Whenever you have two functions that basically do the same thing, write one function with a parameter instead of duplicating code.
  • If you need a function to do the same thing many different ways, a parameter lets one function handle them all.
