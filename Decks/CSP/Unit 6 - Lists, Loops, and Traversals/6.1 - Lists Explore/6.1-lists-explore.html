Unit 6 · Lesson 6.1

Lists Explore

A variable gives a name to one value. Today we will learn how a list lets one name hold a whole collection of values, and we will become the computer again to trace programs that use them.

Pairs work at the stand-up whiteboards, as in Unit 4. Each pair needs a whiteboard, a marker, an eraser, the magnet pointer, two or three list magnets (7 cells, indexes 0 to 6), and the TraceLift program sheets for the tracing rounds. The list programs have no flaps, because students read list values straight from the magnet cells.
Warm-Up

Lists in Everyday Life

Brainstorm lists of information that you run into every day. Name one, and explain why it is useful to keep that information together in a list.

Give students about 2 minutes, then share a few responses and ask what would be harder if the same information were not kept together in a list. Likely answers: playlists, contacts, group chat messages, a class roster, a grade book, a shopping list, a leaderboard, a weekly schedule. Useful because they keep related information together and in order.

Part 1

Creating and Accessing Lists

Setup

The List Magnet

A list is one variable that holds many values in order. On your whiteboard, a list is a magnet with the list’s name written above it.

  • Each cell holds one value, and the cells are numbered starting at 0.
  • A list is named with the same rules as a variable: no spaces, and it cannot start with a number.
  • Cells after the last value are empty, and they are not part of the list.
This replaces the gallon-baggie model from the Code.org lesson. The name above the magnet is the variable (the gallon bag), and each cell is one element (a small baggie). Our magnets have 7 cells, so every list today has at most 7 elements; real lists can be much longer. Write values with quotes for strings, just like in code.
Your Turn · Whiteboards

Make a List

Do This

Choose a name for a list and write it above your magnet. Then fill in the list with 2 to 4 values. Use any mix of numbers and strings, and remember the quotes on strings.

When you are done, share your list with a nearby group. Read it to them as “at index 0 is …, at index 1 is …”

Keep these lists on the boards; students write the code that creates them in a few slides. Check that each list starts at cell 0 and has no gaps.
Vocabulary

Elements, Indexes, and Length

elementelementelement
indexindexindex

Each value in a list is an element, and each element has its own index. Indexes start at 0 and count up. The length of a list is how many elements it contains, so this list has length 3 and indexes from 0 to 2.

Sometimes we think about the whole list by its name, lunchFood. Other times we think about one element inside it.

Point out that the last index is always one less than the length, because counting starts at 0. In the baggie version of this lesson, all the small bags fold into the big bag: the whole list travels under one name.

Your Turn · Whiteboards

Write the Command

Do This

On your whiteboard, write the command that creates the list on your magnet. Then write the command that creates another group’s list, and share both with that group so they can check it.

example
var favSnacks = ["chips", 3, "grapes"];
Common errors: parentheses or curly braces instead of square brackets, missing commas, and missing quotes on strings.
Accessing Elements

Accessing an Element

The expression lunchFood[1] accesses the value at index 1. It also uses square brackets.

On the whiteboard, students find the magnet named lunchFood and read the cell whose index is 1. The highlighted cell on the board is the one being read. Accessing does not remove or change the element.
Check

What Do These Access?

The list lunchFood holds "pizza", "soup", and "nachos". What does lunchFood[2] access? What does lunchFood[0] access?

Answers: lunchFood[2] is "nachos" and lunchFood[0] is "pizza". Students who choose "soup" for index 2 are counting from 1. Have pairs compare with another group before revealing.
Lists and Expressions

Lists in Expressions

When a list access appears in an expression, look up the value in that cell, substitute it, and then evaluate.

This is the same Look up, Substitute, Evaluate routine from Unit 4. The only new part is where the value lives: in a cell of the magnet instead of a variable column. Students write the substituted expression on the board next to the line, since list accesses have no flaps.
Your Turn · Whiteboards

Write Expressions With Your List

Do This

Write three expressions that use accesses to the list on your magnet, like myNumbers[0] + myNumbers[2]. Then trade boards with another group and have them evaluate your expressions.

Remember that + adds numbers but joins strings, so "to" + "day" is "today".

Encourage at least one expression that mixes an access with a literal, such as favSnacks[1] * 10, and one that joins strings. Students who finish early can try an index that is past the end of their list; in App Lab that access gives undefined.
Changing Elements

Assigning to an Element

myNumbers[0] = 5; assigns a value to one index. Discuss with your partner: what will the list contain after line 3 runs?

Read myNumbers[0] = 5 as "myNumbers at index 0 gets 5." Just like variable assignment, the old value is thrown away and replaced, so students erase that one cell and write the new value. The other cells do not change.

Part 2

Changing Your List

Now we will learn three commands that change the length of a list by removing or adding elements.

Changing Your List · removeItem

removeItem(list, index)

Removes the element at the given index. Discuss with your partner: what will the list contain after line 3 runs?

On the magnet, students erase the removed value, then move every value to its right one cell to the left, working left to right. The last filled cell ends up empty, so the length goes down by one.
Changing Your List · appendItem

appendItem(list, item)

Adds an element to the end of the list. Discuss with your partner: what will the list contain after line 3 runs?

Append means "add to the end." A new index is added to the list, and the new item goes there. On the magnet, that is the first empty cell. Nothing else moves.
Changing Your List · insertItem

insertItem(list, index, item)

Inserts an element at the given index. Discuss with your partner: what will the list contain after line 3 runs?

To make room on the magnet, students start at the last element and move each value one cell to the right until the target index is free, then write the new item there. Starting from the right keeps them from writing over a value they still need.

Wrap-Up

Key Vocabulary

var favNums = [74, 53, 22];
List

An ordered collection of elements.

Element

One value in a list, with its own unique index.

Index

A number used to refer to an element in a list or a string.

Length

How many elements a list has. It changes as elements are added or removed.

These are the AP CSP definitions. The length of favNums is 3, and its indexes run from 0 to 2.
Wrap-Up

Lists Are a Data Abstraction

A list lets us name and program with a large collection of information while ignoring the low-level details of how that data is stored and organized in the computer.

That makes programs easier to develop and maintain. Instead of seven temperature variables, an app can keep one list named temps, and the same code works whether the list holds seven values or seven thousand.

Data abstraction is an AP exam term. Connect back to the temperature problem from the start of class.

4. Why is the last index of a list always one less than its length?

Expected: 1) 75 (53 + 22). 2) The list goes 1, 4, 8, then 1, 4, 8, 6, then removing index 2 takes out the 8, leaving 1, 4, 6. 3) 3: the list grows to 4 and then shrinks back to 3. 4) Indexes start at 0, so a list with n elements uses indexes 0 through n minus 1.
