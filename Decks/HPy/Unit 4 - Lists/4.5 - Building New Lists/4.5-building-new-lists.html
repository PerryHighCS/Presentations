The Question

How do we build a new list from an old one?

So far, our loops over a list have produced one value: a count, a total, or an index. Often you want a whole list back instead, such as only the reaction times that beat the average, or every word in lowercase. The program builds a new list from the original, and the original stays as it was.

4.2.10 Looping over Lists

The list accumulator

You already know the number accumulator: start total = 0 and add to it in a loop. A list accumulator works the same way. Start with an empty list, append to it inside the loop, and use it when the loop ends.

The new list grows by one value each time the loop decides to keep something.

a number accumulator
total = 0
for n in nums:
    total += n
a list accumulator
result = []
for v in L:
    result.append(v * 10)
print(result)
Pattern · Filter

Keep only some values

A filter puts an if around the append. Values that pass the test go into the result unchanged, and the rest are skipped.

The result can be shorter than the original, or even empty, but never longer.

main.py
def findLongWords(words, minLength):
    result = []
    for word in words:
        if len(word) >= minLength:
            result.append(word)
    return result

words = ["so", "incredibly", "loud"]
print(findLongWords(words, 4))
# ['incredibly', 'loud']
Pattern · Transform

Change every value

A transform appends a changed version of every value. The result has exactly as many values as the original, in the same order.

Filters and transforms combine naturally: test a value, and if it passes, append a changed version of it.

main.py
def lowerAll(words):
    result = []
    for word in words:
        result.append(word.lower())
    return result

def loudWords(words):
    result = []
    for word in words:
        if word.endswith("!"):
            result.append(word.upper())
    return result

Looping by Index

When the position is the answer

Loop by index when you need to know where a value is, or what is next to it.

findAll collects every index of a target. repeatedWords compares each word with the one before it, to catch typos like the the. A loop by value cannot see the word before, and the loop starts at 1 because index 0 has no word before it.

main.py
def findAll(words, target):
    result = []
    for i in range(len(words)):
        if words[i] == target:
            result.append(i)
    return result

def repeatedWords(words):
    result = []
    for i in range(1, len(words)):
        if words[i] == words[i - 1]:
            result.append(words[i])
    return result
4.2.12 Non-Mutating Functions

The original stays the same

Every function today builds and returns a new list. The caller's list is only read, so it is unchanged afterward. That is called a non-mutating function.

But result.append is a mutating method. That is fine: result is a brand-new local list that the function created itself. Non-mutating means the function does not change its arguments.

main.py
def removeAll(L, v):
    result = []
    for value in L:
        if value != v:
            result.append(value)
    return result

L = [1, 2, 3, 2, 3, 2, 4]
M = removeAll(L, 2)
print(L)   # [1, 2, 3, 2, 3, 2, 4]
print(M)   # [1, 3, 3, 4]

Testing

Test the result and the input

removeAll makes two promises: it returns the list without v, and it leaves L exactly as it was. A good test checks both.

Save a copy of the input before the call, then compare. original = L would only make an alias, which changes along with L, so the test could never fail.

Also test an empty list and a list with nothing to remove. You will write a test like this for each function in today's exercise.

main.py
import copy

def testRemoveAll():
    L = [1, 2, 3, 2, 4]
    original = copy.copy(L)
    M = removeAll(L, 2)
    assert(M == [1, 3, 4])
    assert(L == original)
    assert(removeAll([], 2) == [])
    assert(removeAll([1, 3], 2) == [1, 3])
    print("removeAll passed")

A shortcut for this loop

a loop
result = []
for word in words:
    if len(word) > 5:
        result.append(word.upper())

Python has a shortcut for simple filters and transforms like this one, called a list comprehension. It builds the same list. You do not need to write comprehensions yet. For now, write the loop: it is easier to trace and to debug.

a comprehension
result = [word.upper() for word in words if len(word) > 5]
