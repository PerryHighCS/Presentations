4.2.5 List Mutability

Strings can't change, but lists can

Strings are immutable: once a string exists, nothing can change it. Assigning to s[0] crashes.

Lists are mutable. L[i] = v replaces the value at index i, directly changing, or mutating, the list. No new list is made.

Every tool in the last lesson only read a list. Today's tools change it.

a string
s = "abc"
s[0] = "d"    # crash!
# TypeError: 'str' object does not
# support item assignment
a list
L = [1, 3, 5]
L[0] = "wow"
print(L)      # ['wow', 3, 5]
4.2.8 List Methods

Adding values

L.append(v) adds one value to the end.

L.extend(M) adds each value of the list M to the end. M itself is unchanged.

L.insert(i, v) puts v at index i, so that afterward L[i] == v. Everything from index i on moves one place to the right.

main.py
L = [2, 5, 3]
L.append(4)
print(L)    # [2, 5, 3, 4]

N = [8, 9]
L.extend(N)
print(L)    # [2, 5, 3, 4, 8, 9]
print(N)    # [8, 9]

L.insert(1, 7)
print(L)    # [2, 7, 5, 3, 4, 8, 9]
4.2.8 List Methods

Removing values

L.remove(v) searches for a value and removes its first occurrence. Like index, it crashes when v is missing.

L.pop(i) removes whatever is at an index, and L.pop() removes the last value. pop also returns the value it removed.

remove takes a value. pop takes an index. L.pop(1) does not remove the value 1.
main.py
L = [4, 5, 4, 5, 6]
L.remove(5)
print(L)       # [4, 4, 5, 6]
L.remove(9)    # crash!

L = [5, 4, 3, 2, 1]
v = L.pop(1)
print(L, v)    # [5, 3, 2, 1] 4
w = L.pop()
print(L, w)    # [5, 3, 2] 1

Index Shifting

Inserting and removing move every later value

A list has no gaps. When a value is inserted, every value after it shifts right and its index goes up by one. When a value is removed, every value after it shifts left and its index goes down by one. Assignment with L[i] = v and append at the end move nothing.

Watch saved indexes. An index you saved before an insert or remove may now point at a different value.
4.2.8 List Methods

Changing the order

L.sort() puts the values in order from smallest to largest. Add reverse=True to sort from largest to smallest.

L.reverse() flips the order of the values. It does not sort.

Both rearrange the list in place: the list object holds the same items but they are now in a new order.

main.py
L = [2, 1, 4, 3]
L.sort()
print(L)    # [1, 2, 3, 4]

L.sort(reverse=True)
print(L)    # [4, 3, 2, 1]

L = [2, 1, 4, 3]
L.reverse()
print(L)    # [3, 4, 1, 2]
Return Values

Most mutating methods return None

append, extend, insert, remove, sort, and reverse all change the list and return None. You already have the list, so there is nothing to hand back.

pop is the exception. It returns the removed value, because otherwise that value would be lost.

A classic bug: words = words.sort() sorts the list, then replaces words with None.
main.py
L = [3, 1, 2]
x = L.append(5)
print(x)        # None
print(L)        # [3, 1, 2, 5]

y = L.pop()
print(y)        # 5

words = ["b", "a"]
words = words.sort()
print(words)    # None

4.2.9 List-Related String Methods

join() turns words back into text

split turns text into a list. c.join(L) goes the other way: it builds one string from a list of strings, with the separator c between each pair.

Notice that join is a method of the separator, not of the list. Every value in L must be a string.

main.py
words = "the fan is loud".split(" ")
words[3] = "quiet"
words.append("now")
text = " ".join(words)
print(text)
# the fan is quiet now

print("-".join(["a", "b", "c"]))
# a-b-c
