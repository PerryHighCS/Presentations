Phase 1 · Solution

The accumulator pattern

An accumulator is a variable that builds up a result one loop pass at a time. The pattern has three parts.

  • Before the loop, start it at a neutral value: total = 0 and count = 0.
  • Inside the loop, update it with each new value: total += ms and count += 1.
  • After the loop, use it: total / count is the average.
main.py
total = 0
count = 0
while True:
    ...      # play one round, get ms
    total += ms
    count += 1

average = total / count
print("Average:", round(average), "ms")
If a student quits before playing a round, count is 0 and the division crashes. Worth pointing out, and an if statement fixes it.

Why It's Hard

The times are gone before you need them

To know whether a try beat the average, you need the average. But the average is not known until the last round is over, and by then every earlier time has been overwritten.

You could store each time in its own variable, t1, t2, t3. But how many variables would you write? The player decides how many rounds to play while the program runs, long after you wrote it.

This problem shows up everywhere. A guessing game that says "you already guessed that" must remember every guess so far. An animation that adds a dot wherever you click must remember every dot. In each case, the number of values is unknown, and the program has to come back to them later.
4.1 Getting Started

A list keeps every value

A collection stores any number of values under one name. This unit is about the most common one, the list. Other collections, like tuples, sets, and dictionaries, come in later units.

Start with an empty list, []. Each round, times.append(ms) adds the new time to the end. After the game, every time is still there, so a second loop can compare each one to the average.

main.py
times = []
while True:
    ...      # play one round, get ms
    times.append(ms)

average = sum(times) / len(times)
faster = 0
for t in times:
    if t < average:
        faster += 1
print(faster, "tries beat your average")
append and sum get full treatment in 4.3 and 4.2. Here they only need to read the code. len works on lists just as it does on strings.

4.2.1 Introduction

Writing a list

A list literal is a left bracket, zero or more values separated by commas, and a right bracket.

A list can hold any type of value, and one list can mix types. [] holds no values, but it is still a list, with length 0.

Every list has the type list.

main.py
L = [42, True, "wahoo"]
print(L)       # [42, True, 'wahoo']
print(len(L))  # 3
print(type(L) == list)  # True

L = []
print(L)       # []
print(len(L))  # 0
4.2.2 Creating Lists

Three more ways to make a list

list() makes a new empty list. [v] * n makes a list of n copies of v, so the length can come from a variable. list(range(n)) makes the consecutive integers from 0 up to, but not including, n.

Why a capital L? A lowercase l looks like the digit 1. Short list names use capitals: L, M, N. Longer names, like words, stay lowercase.
main.py
L = list()
print(L)        # []

n = 5
L = [42] * n
print(L)        # [42, 42, 42, 42, 42]

L = list(range(n))
print(L)        # [0, 1, 2, 3, 4]
Checkpoint · Creating Lists

Which one does not create a list of length 4?

  • A[2, 6, 8, 15]
  • Blist(range(0, 20, 5))
  • Crange(2, 6)
  • D[42] * 4
Answer: range(2, 6). It describes four numbers, but it is a range, not a list. Wrapping it as list(range(2, 6)) would make a list. Option B is [0, 5, 10, 15].
4.2.3 List and String Similarities

Lists and strings are both sequences

A sequence is an ordered collection of values. A string's values are always characters, while a list's values can be anything. Because both are sequences, almost everything you learned about strings already works on lists.

a string
s = "loud"
print(s[0])     # l
print(s[-1])    # d
print(s[1:3])   # ou
print(len(s))   # 4
a list
L = ["so", "very", "loud", "!"]
print(L[0])     # so
print(L[-1])    # !
print(L[1:3])   # ['very', 'loud']
print(len(L))   # 4
Indexing

Every value has two indexes

As with strings, list indexes start at 0, so a list of length 4 has indexes 0 through 3. Negative indexes count from the right end: L[-1] is the last value and L[-2] is the one before it.

0123 'amazing''terrible''okay''perfect' -4-3-2-1

For any list L, the index -k names the same value as len(L) - k. Here, L[-2] and L[2] are both 'okay'.

Invalid Indexes

An index past the end crashes

A list of length 3 has indexes 0, 1, and 2. Asking for L[3] stops the program with an IndexError.

The empty list has no legal indexes at all, so even L[0] crashes. Code that looks at the first item of a list has to handle a list with no items.

main.py
L = [42, True, "wahoo"]
print(L[3])

E = []
print(E[0])
IndexError: list index out of range
Slicing

A slice is a new, smaller list

L[start:end:step] works exactly as it does on strings. It starts at start and goes up to, but not including, end. Each of the three parts is optional: leave out start to begin at index 0, end to go all the way to the end, or step to take every value.

Unlike indexing, slicing never crashes. A slice that runs past the end just stops at the end, and a slice that selects nothing is [].

main.py
L = [4, 5, 6, 7, 8, 9]
print(L[2:5])    # [6, 7, 8]
print(L[:4])     # [4, 5, 6, 7]
print(L[4:])     # [8, 9]
print(L[0:5:2])  # [4, 6, 8]
print(L[4:1:-1]) # [8, 7, 6]
print(L[::-1])   # [9, 8, 7, 6, 5, 4]
print(L[1:1])    # []
print(L[4:8])    # [8, 9]
print(L[6:])     # []
Checkpoint · Indexes and Slices

Which one is not equal to 3?

Start with L = list(range(1, 6)).

  • AL[-3]
  • BL[0] + L[1]
  • Clen(L[:3])
  • DL[2]
  • EL[-2]
L is [1, 2, 3, 4, 5]. L[-2] is 4. Everything else is 3: L[-3] and L[2] are both 3, 1 + 2 is 3, and L[:3] is a three-item list.
Looping

Loop by value or by index

by value
L = [42, True, "wahoo"]
for v in L:
    print(v)

By value is simplest when you only need each value. v becomes each value in turn.

by index
L = [42, True, "wahoo"]
for i in range(len(L)):
    print(i, L[i])

By index is what you need when the position matters: numbering the values, skipping some, or comparing neighbors. The legal indexes are exactly range(len(L)).

From Text to a List

split() turns a string into a list of words

You have used s.split(c) in a for loop. It actually returns a list of strings, the pieces of s between each separator c. Now that we have lists, we can store that list and use it.

main.py
sentence = "my dog likes long walks"
words = sentence.split(" ")
print(words)
# ['my', 'dog', 'likes', 'long', 'walks']
print(len(words))     # 5
print(words[-1])      # walks
print(words[:2])      # ['my', 'dog']
